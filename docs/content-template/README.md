# 单文件教程模板

本目录可直接作为内容校验命令的输入，README.md 不会被识别为模块。复制 `Linux 基础.md` 并改名即可编写新模块，无须填写任何数据库 ID。

在仓库根目录运行：

```bash
npm --prefix web run content:check -- ../docs/content-template
```

该命令只校验本地文件，不访问 GitHub、数据库或 Docker，不发布内容。输出文件、章节数、题目数、权限和时长，错误时退出码为 1，并给出文件、行号和字段；不会输出标准答案。

## 编写规则

1. 一个 `.md` 文件对应一个模块，文件名去掉扩展名即模块名称。模块文件直接放在内容目录第一层；子目录中的 MD 不自动导入。
2. 使用 `---` 包住文档头。配置可以留空；省略分类为未分类，难度默认为 beginner，章节默认为登录可读。不要填写 title、id、slug 或数据库 UUID。
3. 文档头之后直接从 `# 章节名称` 开始。一级标题划分章节、出现顺序决定章节顺序；二级及以下标题属于章内小节。章节名不能重复。
4. 章节内使用 `quiz` 围栏编写题目。不能缩进或放进列表、引用、模块介绍中；必须闭合。普通 bash、text 等代码块不会作为题目。
5. 模块名称和章节标题最多 160 字，简介最多 500 字，学习目标最多 12 项、每项最多 200 字。

文档头支持以下字段，未使用的可选项可以删除：

| 字段 | 用途 |
| --- | --- |
| summary | 模块列表里的简介 |
| description | 模块详情介绍；可用 YAML 多行文本书写 Markdown |
| category | 后台分类 slug；省略为未分类，实际分类是否存在由导入阶段检查 |
| difficulty | beginner / intermediate / advanced |
| access | 模块内章节的默认权限：public / authenticated |
| learningOutcomes | 学习目标文本列表 |
| chapters | 按章节标题配置例外项，只支持 access 和 durationMinutes |

时长必须为 1–1440 分钟整数，省略时不展示。chapters 配置里的标题必须与实际一级标题的可见文字一致；标题改名后也要修改对应配置。

## 题目格式

````md
```quiz
prompt: 查看当前用户名使用什么命令？
answer: whoami
normalization: trim
errorHint: 想想“我是谁”对应的命令。
```
````

prompt 和 answer 必填，normalization 默认为 trim，errorHint 可省略。题目提示支持 YAML 多行 Markdown；同一章节不能出现重复题干。数字、yes/no、true/false 等答案请用引号明确写成文本，例如 `answer: "123"` 或 `answer: "true"`。

- exact：完全匹配，保留空白和大小写。
- trim：忽略首尾空白。
- trim_casefold：忽略首尾空白和大小写；沿用现有服务端规则，不压缩命令内部空格。

私有仓库中的答案属于服务端判题配置。生成学习正文时 quiz 块会被移除，公开题目仅包含题干。请勿把标准答案、密钥放在你不希望公开的普通正文、命令示例或模块简介里。

## 配图

图片相对于当前 MD 的位置引用，例如 `![终端输出](images/terminal.webp)`。先在仓库里放入对应文件，再添加引用。支持 PNG、JPEG、WebP、GIF 和 AVIF，单图不超过 10 MiB。

允许解析后仍在仓库根目录内的 `..`；不允许外链图片、Data URL、绝对路径、越界路径或符号链接。缺失图片会阻断校验。普通外部网页链接不受图片存储约定影响。

本地校验命令只发现并检查图片文件，不复制文件或生成访问 URL；后台确认导入时会准备持久资源，并通过章节权限校验后提供图片。

## 更新与改名

正文、答案和排序可以调整。不要用标题里的数字表达顺序，章节顺序就是文件中的实际顺序。

模块文件改名、章节标题改名、题干改写时，在后台同步预览中确认原记录关联，才能可靠保留 ID 和进度。正式导入通过后台“Git 教程同步”完成；本地校验成功不代表已经导入或上线。
