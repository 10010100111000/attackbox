# 个人中心

`/me` 从单一昵称表单调整为个人学习入口。桌面采用账户侧栏与内容区域的双栏布局，手机端将栏目导航收成横向分段导航。沿用学习区的石墨／深海主题与 Lucide 图标，不添加独立的个人中心主题或重复的全局导航。

## 栏目与交互

| 地址 | 内容与主要操作 |
| --- | --- |
| `/me` | 最近学习记录；优先继续最近未完成的模块；按全部／进行中／已完成筛选。 |
| `/me?tab=challenges` | 已通过阶段的挑战记录；展示阶段进度和完成状态；点击进入挑战。 |
| `/me?tab=profile` | 修改昵称、查看登录邮箱、进入已有的密码找回流程。 |

栏目使用真实链接，支持刷新、浏览器前进后退及直接访问。访客显示登录入口，不请求个人记录。各记录栏目按需加载，提供加载、错误重试、无记录与筛选无结果状态；没有定时查询。

继续学习使用服务端计算的 `resumeChapterSlug`，不会将已完成模块当作待续任务；已完成模块的记录进入模块目录供重新阅读。筛选只影响记录列表，继续学习卡片保持位置，避免筛选按钮随布局跳动。

昵称表单在未修改、内容无效或保存中禁用提交。支持取消修改；切换个人中心栏目保留输入，离开个人中心时提示未保存的修改。保存失败保留输入，成功后使用服务端返回的规范化昵称直接更新侧栏和头像菜单，不再额外查询会话。

## 使用的数据

- `GET /api/me/learning`：现有最近 20 个已发布模块的记录。达到 20 条时明确显示记录范围，不将这些记录当作全站累计统计。
- `GET /api/me/challenges`：现有至少通过一个阶段的已发布挑战。启动过但尚未通过阶段的挑战不会伪装为已记录项目。
- `PUT /api/me/profile`：只修改当前会话用户的昵称，返回保存后的 `displayName`；邮箱、角色与权限不可通过此接口修改。

缓存按当前用户 ID 区分，并沿用账户切换时的缓存清理。页面不添加积分、学习时长、登录设备或虚构的环境统计；CLI／GUI 和靶场生命周期仍由原有组件管理。

本轮没有数据库结构变更，不新增迁移。

## 验证

在本地隔离 PostgreSQL 和 Chromium 上运行：

```bash
CONTENT_TEST_DATABASE_URL=postgres://.../personal_test \
CONTENT_TEST_BASE_URL=http://127.0.0.1:3000 \
npm --prefix web run test:personal-center
```

测试真实模块、章节与挑战阶段进度，覆盖继续学习目的地、筛选及布局稳定、栏目刷新、昵称取消与失败重试、规范化保存、未保存离开提示、头像名称同步、深海及窄屏布局、真实退出再登录后的账号隔离，以及新账号的空状态与读取失败后的恢复。

可设置 `PERSONAL_SCREENSHOT_DIR` 导出石墨、深海、手机与空状态截图。通知中心与登录导航分别沿用 `test:notifications` 和 `test:auth-navigation` 回归测试。
