# 账户菜单与站内通知

本轮完成共享账户菜单、基础个人资料、管理员公告与用户通知中心。首页、登录页、学习页、管理后台及独立 CLI／GUI 工作台复用 `UserMenu`，替换原先分散的账户入口与外观按钮。

## 交互与边界

- 头像菜单包含个人中心、通知、管理员后台入口及退出登录。未读时显示提示点，菜单内显示数量；仅管理员可见后台入口。
- 石墨／深海使用紧凑的分段滑块，支持鼠标和键盘，沿用本机外观偏好存储。刷新和跨页面保持选择，不新增服务端主题配置。
- `/me` 提供基本账户资料与昵称修改；邮箱只读。学习统计、排行榜、头像上传和通知偏好留待后续。
- `/notifications` 按发布时间分页，点击后展示正文并保存已读。正文是纯文本，允许换行及可选本站页面链接。
- `/admin/notifications` 提供发布前预览、发布、历史列表和撤回。第一版只做面向所有登录用户的站内公告，不提供邮件、外部推送或定向发送；之后注册的用户也能阅读尚未撤回的公告。
- 不设通知轮询。进入带头像的页面、切换账户或打开菜单时读取未读数；进入通知中心读取列表，点击消息保存已读。管理员列表仅在进入、翻页、发布或撤回时读取。

## 数据与权限

`announcements` 保存一份公告正文、发布者与发布时间，撤回保留记录但不再向普通用户展示。`notification_reads` 以公告和用户为联合主键，已读操作可重复提交。发布时不为所有用户批量创建收件记录。

发布、后台列表和撤回必须通过服务端管理员权限校验；用户列表、未读和已读接口使用会话中的用户 ID，不接受请求指定其他用户。个人资料接口只允许更新当前用户的昵称。相关页面和接口使用私有、禁止缓存响应，写入接口检查跨站来源；消息按纯文本展示。

## 部署

新增 `0001_notifications`，不改写 `0000_compose_platform`。配置 `DATABASE_URL` 后运行：

```bash
npm --prefix web run db:migrate
npm --prefix web run build
```

数据库迁移需在切换新应用之前执行。上一轮全新基线部署可直接追加此迁移；空库会依次创建基线和通知表，不需要清库。

## 验证

默认测试与 TypeScript 检查外，本轮使用本地隔离 PostgreSQL 和 Chromium 验证发布、撤回、已读幂等与账户隔离、权限和跨站校验、纯文本展示、昵称保存、主题持久化、弹出层样式、键盘关闭、窄屏布局，以及退出失败后的身份保持。登录导航回归覆盖慢接口不阻塞登录跳转。

```bash
# 先迁移并启动连接同一隔离测试库的本地 Nuxt 服务
CONTENT_TEST_DATABASE_URL=postgres://.../account_test \
CONTENT_TEST_BASE_URL=http://127.0.0.1:3000 \
npm --prefix web run test:notifications

AUTH_TEST_BASE_URL=http://127.0.0.1:3000 \
npm --prefix web run test:auth-navigation
```

仅本地测试，未连接实际部署服务器，也未向真实用户发送通知。
