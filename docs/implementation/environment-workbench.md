# CLI／GUI 工作台

正文工具栏持续显示沙箱状态、服务端到期时间倒计时及环境操作菜单。创建和释放属于同一沙箱会话，不依赖练习面板是否展开。Docker 靶机仍是独立实例，不显示虚构到期时间。

正文面板保留拖动调整高度、收起和独立打开；移除重复的关闭、展开和面板内释放入口。收起不关闭连接。CLI 内单个终端的关闭仍结束该终端连接，不释放整个沙箱。

## 独立页面

- `/term`：无学习页导航与目录，占满视口。支持新建多个终端窗口、拖动、右下角缩放、平铺、层叠、最小化恢复、最大化和全部关闭，快捷键 Ctrl+Alt+T 新建。延续旧 CLI 的窗口交互，用 Vue 窗口层复用当前 xterm 连接组件，不恢复旧 SPA、全局 WinBox 或旧接口。
- `/gui`：无学习页导航与目录；紧凑工具栏保留环境状态、释放菜单及浏览器全屏。复用 noVNC，自适应模式开启远端 resizeSession，原始尺寸模式停止缩放与动态调整。服务端是否接受动态分辨率需真实 VNC 验收，不把画布拉伸视为远端已调整。

正文点击独立打开会复用命名窗口，已有工作台只聚焦不重载；新 CLI 页面创建新的 Shell，不宣称从正文迁移原有 Shell。浏览器决定使用标签页或窗口。浏览器阻止弹出时显示提示。

GUI 使用同源 BroadcastChannel：新的桌面连接成功后通知其他页面暂停其桌面连接。原页面显示“在此继续操作”；用户明确继续后，连接成功才再通知其他页面。关闭独立页面不会释放沙箱，也不会自动抢回 GUI 焦点。尚未支持 BroadcastChannel 的浏览器不提供自动交接，仍依赖明确的连接／断开操作。

环境状态请求通过共享 Nuxt 会话状态和单个订阅计时器协调；多个页面通过消息提示刷新，但每页独立验证服务端状态，不跨页面传递票据。账户变化会清除旧状态，未确认的释放不显示成功。定时刷新保留，重连和多窗口共用现有服务端权限与一次性 Ticket。

## 验证

`npm test`、TypeScript、生产构建；本机测试服务配置 `CONTENT_TEST_DATABASE_URL`、`CONTENT_TEST_BASE_URL`、`NODE_TEST_CLUSTER_SECRET` 后运行 `npm run test:workbench`。测试使用本地 Worker／PTY／RFB 协议模拟器，不是远程真实沙箱验收。

已验证：正文面板之外的倒计时、独立页面视口、多终端平铺、重复打开不重载、GUI 双向交接、收起后的释放与同一实例复用。原沙箱浏览器回归覆盖 Ticket、重连、管理员释放和节点设置。服务器无需新增数据库迁移；本轮未连接 VPS。
