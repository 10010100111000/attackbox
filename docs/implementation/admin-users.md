# 管理员用户管理

本轮接入真实用户、学习记录与当前练习环境，不新增会员、账号删除或历史版本系统。沿用现有表，无新增数据库迁移。

## 页面

- `/admin/users`：邮箱／昵称字面搜索、状态和角色筛选、20 条分页。列表显示真实账号状态、最近登录时间与当前环境。
- `/admin/users/:id`：账号信息、有效网页登录数量、学习统计、最近 20 个模块及当前实例。管理员页面采用桌面布局，账号与环境并列，学习记录置于下方；沿用石墨／深海主题与 Lucide 图标。
- 学习统计只计算当前已发布模块对应的章节记录。下架隐藏对应统计，重新发布后记录恢复；停用账号不删除学习记录。
- 本次运行时长根据当前实例启动时间计算。没有采集历史 CLI／GUI 时长，不展示虚构历史用量。

## 接口

所有接口要求已激活管理员，返回 `private, no-store`，写操作校验请求来源。列表和详情仅白名单返回公开账号字段，不返回密码摘要、会话凭证、验证凭证或题目答案。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/admin/users?search=&status=&role=&page=1` | 筛选与分页；每页 20 条 |
| GET | `/api/admin/users/:id` | 账号、有效会话数量、学习记录和当前环境 |
| PUT | `/api/admin/users/:id/status` | `{ "suspended": true/false }`，停用或恢复 |
| POST | `/api/admin/users/:id/revoke-sessions` | 撤销全部网页登录会话 |

停用与恢复返回 `{ status, cleanup }`，清理结果为 `none`、`released`、`pending`。账号状态和会话撤销先提交，再等待 Worker 清理；清理失败不恢复账号，也不隐藏占用，管理员可在运行实例页重试。后台状态变更通过 PostgreSQL 事务锁序列化并重新校验操作者，拒绝停用自身并保留可用管理员。内存调度器在提交后同步阻止该用户的新建及 Ticket，覆盖已通过请求鉴权但尚未完成身份分配的启动请求；恢复后移除阻止状态。等待 Worker 不会阻塞其他账号的状态变更。

恢复已验证账号为 `active`，未验证账号为 `pending`；恢复不会复活被撤销的会话。撤销登录只撤销网页登录会话，不承诺关闭已经连接的 CLI／GUI；需中止当前环境时使用停用或实例释放操作。Worker 断开时，已建立连接的实际终止时间仍取决于 Worker 恢复及清理确认。

邮箱验证在锁定用户后重新核验账号与凭证，旧验证链接不能激活已停用账号；登录在密码校验后锁定并重新检查账号状态及密码摘要，防止停用或密码重置期间签发新会话。安全操作记录写入现有 `audit_logs`。

## 本地验证

使用隔离的本机 PostgreSQL 数据库（库名以 `_test` 结尾），迁移完成后启动生产构建的 Nitro，启用测试节点调度。测试进程配置：

```bash
CONTENT_TEST_DATABASE_URL=postgres://postgres@127.0.0.1:55457/attackbox_users_test \
CONTENT_TEST_BASE_URL=http://127.0.0.1:18920 \
SANDBOX_CLUSTER_SECRET=test-cluster-identity-0000000000000000 \
npm --prefix web run test:users
```

这里的 cluster secret 仅为本地 fixture 值，需与测试 Nitro 相同。测试 Worker 使用 `test-node`、数据端口 `18443`，不可与其他使用该端口的沙箱测试同时运行。浏览器依赖 Playwright 和 `/usr/bin/chromium`。

覆盖真实接口权限、字段隔离、字面搜索、筛选和分页、学习统计、停用及会话撤销、恢复不复活旧会话、未验证账号恢复、验证凭证重放、登录签发时的并发停用、管理员并发互相停用、Worker 清理失败与重试，以及浏览器搜索、详情、停用／恢复和主题切换。Worker 是协议 fixture，不验证 Btrfs／Cgroup 内核隔离。
