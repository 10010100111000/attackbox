# 学习首页管理

后台入口 `/admin/learn-home`，前台 `/learn`。首次发布本功能前，执行 `sudo scripts/manage.py migrate` 创建 `learn_home_settings`。

## 内容配置

- 推荐区：整体显示开关、自动轮播、5–30 秒间隔。
- 最多 10 项：标签、标题、说明、按钮文字、本站跳转路径、终端装饰文字及说明。
- 推荐项可新增、删除、上移、下移和单独隐藏；列表顺序就是播放顺序。
- 跳转可选择已发布模块或路线，也可填写本站路径。保存时校验字段长度、路径安全和 ID 唯一性；链接目标以后下架时仍由目标页面的访问规则处理。
- 预览与前台共用展示组件。修改仅存在本地表单，保存后直接生效；这里没有独立草稿／发布流程。

保存采用版本号并发检查，发生冲突会保留表单，管理员可重新载入最新配置后再编辑。离开页面前提醒未保存修改。公开接口仅返回启用的推荐项，不暴露隐藏项及编辑者。

## 播放行为

多项内容才启动计时器；单项不显示分页或启动计时器。支持分页点击、左右方向键和播放／暂停按钮。鼠标悬停、键盘聚焦、后台标签页会暂停，恢复后重新计时。遵循系统减少动态效果的偏好。禁用推荐区或没有可见项时不占据首页空间。不使用状态轮询。

模块、分类、路线和个人继续学习区保留现有数据来源，本轮不增加重复管理入口。暂不提供图片上传、广告统计、定时投放或任意布局编辑。

## 本地验证

`npm --prefix web test` 包含首页配置校验。`tests/learn-home-browser.test.mjs` 使用隔离的本机 `_test` 数据库和运行中的 Nuxt，通过 `CONTENT_TEST_DATABASE_URL`、`CONTENT_TEST_BASE_URL` 指定；验证管理员权限、真实保存和重载、冲突、隐藏项过滤、轮播与暂停。

## 内容发现与模块卡片

推荐区缩小，标题与说明各最多展示两行。新安装默认手动播放；已有后台保存的自动轮播设置保持不变。继续学习使用紧凑横条。模块列表支持难度筛选、最新发布／最近更新排序，并展示配置过的章节总时长。最近学习记录中的模块展示真实进度及继续入口，未获得进度的模块不伪造学习状态。

模块封面由教程 Markdown 的 `cover` 字段维护，见 [Git 内容使用说明](git-content-sync-usage.md)，不需要新增数据库迁移。
