# 学习模块／章节关联靶机模板

本轮只实现配置关联与学习页说明展示，没有创建容器、实例任务、Docker 接口或网络规则。

## 配置规则

- 模块设置新增“实验环境 → 默认靶机模板”，可选择已启用模板或不关联。
- 章节设置提供三种模式：继承模块默认、本章不使用、本章另选模板。新章节默认继承。
- 本章另选必须指定有效且启用的模板，切换为继承或关闭时清除章节模板引用。
- 已停用的模板不能新关联。已有模块／章节可以保留其引用并继续保存其他内容，学习页显示通用“暂不可用”状态；重新启用后恢复说明展示。
- 模板列表加载失败时禁用选择并保留原配置，可重试，不将失败误当成解除关联。选项等待客户端挂载后才可操作，避免 SSR 首屏丢失首次选择。
- 继续沿用模块“保存为草稿／保存并发布”及并发修改规则，关联与其他模块内容在同一事务中保存。

章节继承不会复制模板，也不意味着已建立跨章节运行实例。未来运行系统按模块／章节归属创建实例，本轮没有提前实现实例逻辑。

## 学习页与权限

章节正文上方显示可折叠的实验环境说明：模板名称、教学描述、容器内服务端口、访问说明，以及模块默认／本章指定的来源。未关联或本章关闭时不展示卡片。

卡片明确提示“尚未开放在线启动”，没有假启动按钮、目标地址或运行状态。现有 CLI／GUI 攻击端入口保持原行为。

章节接口在检查模块发布、登录和章节进度权限后，在同一只读一致性事务中解析模板。下架或被锁章节不会返回环境信息。学习者只接收白名单字段，不返回镜像、项目来源、管理修改标识或停用模板的具体内容。响应继续使用 private/no-store。

## 实现入口

- Schema：模块 `default_target_template_id`，章节 `target_mode` 与 `target_template_id`，外键和模式／引用一致性约束；对应数据库定义为 `0007_learning_target_bindings.sql`。
- 管理选择：`GET /api/admin/target-templates/options`，仅管理员可访问，只返回 id、名称、启用状态，不受模板列表分页影响。
- 保存：现有模块创建／更新接口增加上述可选字段；字段缺省时保留已有关联，旧调用不会静默清空配置。模板检查带共享锁，避免与停用修改交错。
- 阅读：章节 GET 响应增加 `target`，为 null、通用 unavailable，或安全的 configured 说明。

数据库继续按全新部署规划；未操作远端数据库。

## 本地测试

`npm run test:learning-targets`，使用本机独立 `_test` PostgreSQL 与生产构建 Nitro，通过 `CONTENT_TEST_DATABASE_URL`、`CONTENT_TEST_BASE_URL` 配置。

覆盖继承、关闭、章节覆盖、缺省保留、无效 ID／模式／缺少模板、非法保存回滚、停用后的既有引用保存与新引用拒绝、访问权限与下架隔离、公开字段白名单，以及 Chromium 实际选择、发布和阅读说明。

本轮验证通过：82 项常规测试、关联接口与 Chromium 流程、原有内容生命周期／学习进度及学习浏览器回归、TypeScript、生产构建与 Drizzle 无差异检查。测试服务与数据库均为本地临时资源，结束后清理。

下一轮只做挑战内容管理与前台展示、任务判题和完成记录，并关联现有模板；Docker 启停仍单独迭代。
