# 下一小轮：Docker 目标启动与停止

状态：网络底座已编写并完成单元测试与真实 Docker 网络创建／复用测试；完整跨桥连通性待验收，Worker 容器启停已实现，Nuxt 与页面接入尚未实现。先完成 Docker 运行，再做个人空间。

## 最小交付

先支持一个节点、单容器镜像、独享目标。教学模块／章节和挑战共用同一套服务端解析与 Worker 操作；浏览器只提交业务场景，不指定镜像、节点或 Docker 参数。

- 启动：解析已发布且当前用户有权限访问的内容及启用模板，取得服务端配置快照，建立实例归属，再交给 Worker 创建。
- 查询：准备中、就绪、停止中、清理待确认、失败；就绪后显示同节点攻击环境可访问的容器地址和服务端口。
- 停止：用户只能停止本人实例，管理员可处理异常实例；必须确认容器和网络资源移除，再清除占用。
- 同用户＋模块默认环境跨章节复用；章节另选按章节归属；挑战按挑战归属。不同场景不因模板相同而共享。
- 重复启动和多标签页复用同一实例；创建／停止使用幂等任务标识，超时不直接视为未创建或已停止。

本小轮不加入共享、重置、自动到期回收、多容器、Compose、镜像构建或个人空间。测试后停止所有测试实例，不将本轮部署作为无人值守正式运行。

## 网络架构

保留 Worker 的 `br-attackbox` 和沙箱网段。Worker 通过本机 Docker API 管理另一张独立 Docker bridge 网络，例如 `br-ab-targets`、`10.201.0.0/16`。两个网段通过宿主机路由双向访问，不合并网桥，不限制实验端口，不在两个网段间做 NAT。

配置和使用步骤见 [Worker Docker 网络](worker-docker-network.md)。第一版单节点内让攻击环境与目标位于同一节点，不返回不可达的跨节点地址。独享表示生命周期与业务归属，不承诺用户间网络隔离。容器不开放公网端口映射，不使用 host 网络、特权、宿主目录或 Docker Socket 挂载。

## 前后端分工

- Nuxt：模板和权限解析、业务归属、配置快照、唯一实例约束、任务状态和用户／管理员 API。
- PostgreSQL：目标实例和操作记录，保存 Worker 容器标识；不复用攻击端瞬态记录的全部重启策略。
- Go Worker：通过本机 Docker Engine API 创建、启动、检查与删除，只操作带本系统归属标签的目标，不清理无关容器。
- 心跳与恢复：独立上报 Docker 目标清单。Worker／Control 重连按容器标签与持久归属核对，避免直接清理所有未知公共 Docker 容器。
- 镜像准备：拉取时间单独显示为准备中；镜像错误和网络配置错误明确反馈。服务端根据配置端口或健康信号确认就绪，不把 Docker running 自动等同服务可用。

## 页面交互

目标卡片由“环境说明”升级为实际状态：未启动显示启动目标；准备中禁止重复操作；就绪显示地址与停止；清理待确认保留占用并提供刷新，不允许重复开新实例。模板停用只阻止新启动，不冒充已有实例已停止。

没有 Docker 能力或网络未配置的节点显示明确原因，不出现始终失败的假就绪按钮。原 CLI／GUI 攻击端状态与目标状态分开显示。

## 网络实现进展

- 已恢复原有沙箱同桥隔离；靶机使用独立网桥和独立网段。
- Worker 幂等创建／复用带归属标签的 Docker 网络，检查网段、网桥、网关及不做 NAT 的配置；冲突时报错，不删除重建。
- 使用 Docker iptables 后端的 DOCKER-USER 链与 Worker 专属 nftables 表协作放行跨桥流量，并保护宿主机；不修改全局 FORWARD 策略。
- Docker Engine 27.5+，API 1.47；暂不支持 Docker 原生 nftables 后端。Docker 使用 iptables-nft 不等同于原生 nftables 后端。
- 单元测试、Go vet、真实 Docker 28.4.0 网络创建／复用／清理通过。当前环境缺少 NET_ADMIN 和 nft 命令，未加载真实转发规则，未完成沙箱到靶机及反连验收。没有连接远程 VPS。
