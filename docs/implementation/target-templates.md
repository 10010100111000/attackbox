# 靶机模板基础管理

已实现，范围仅限静态配置管理，不调用 Docker、不改网桥、不连接远程节点，不添加学习或挑战关联。

## 页面

- `/admin/target-templates`：名称／镜像搜索，每页 20 项，启用状态、服务端口、编辑入口及空态／错误／刷新。
- `/admin/target-templates/new`：首次保存才创建记录，离开未保存内容需确认。
- `/admin/target-templates/:id`：编辑、启用／停用、字段错误反馈、保存状态；409 冲突保留输入并要求明确重新读取。刷新／关闭浏览器同样有未保存提醒。

页面使用现有后台主题与 Lucide 图标。名称输入收窄，镜像保留较宽空间；服务端口和访问说明单独分组。启用仅表示模板以后可以被关联，不代表镜像有效或目标正在运行，没有启动、重置或虚构统计入口。

## 数据与校验

`target_templates` 保存名称、用途说明、镜像、来源链接、结构化端口、访问说明、启用状态、时间与乐观锁。更新通过带版本条件的单条 SQL 完成，旧版本返回 409，不覆盖新值。

前后端复用 `web/shared/target-templates.ts` 校验：

- 名称必填、最多 120 字符，用途最多 500 字符，访问说明最多 4000 字符。
- 镜像为受支持的 Docker 引用子集，要求明确 tag 或完整 sha256 digest；支持常用仓库路径和 registry 端口。不访问仓库或拉取镜像。
- 可选来源仅接受不含用户名密码的 HTTP／HTTPS URL。
- 最多 20 个容器内服务端口，整数范围 1–65535；协议为 tcp／udp，同协议同端口不能重复，同号不同协议允许。
- 仅白名单字段存入数据库，忽略任意特权、挂载等额外运行字段。本轮没有密钥或环境变量配置。

已更新 Drizzle schema、数据库定义 SQL 与 snapshot，沿用项目数据库初始化工具；后续部署按全新库规划，不做旧数据兼容。本次没有清理或修改远端数据库。

## 接口

管理员专用 GET 列表、POST 创建、GET 详情、PUT 更新，路径均为 `/api/admin/target-templates` 及其 `/:id` 子路径。不提供 DELETE。接口和后台页面禁止共享缓存，写请求校验来源，所有操作要求已激活管理员。

## 验证

- `npm test`：包含镜像、URL、端口与运行字段白名单校验。
- `npm run test:target-templates`：配置 `CONTENT_TEST_DATABASE_URL`（本机独立 `_test` 数据库）和 `CONTENT_TEST_BASE_URL`（本机生产构建 Nitro）。验证权限、404／非法请求、跨站拒绝、并发保存冲突、搜索分页，以及 Chromium 实际新建、编辑、停用／恢复、离开提醒、冲突保留输入和重新读取。
- TypeScript 检查、生产构建与 Drizzle schema 无差异检查。

本轮结果：82 项常规测试、模板接口／Chromium 端到端测试、原有学习浏览器回归、TypeScript、生产构建及 Drizzle 无差异检查全部通过。本地测试服务和临时数据库已清理。
