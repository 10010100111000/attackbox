# Compose 架构实施状态

五轮代码收敛已完成，当前以全新部署为基线，不实现旧服务或数据转换。

1. labnetwork：实例 internal 网络、地址预留、namespace 身份核验、沙箱额外网卡、宿主保护。
2. labcompose：多服务项目、固定镜像、预算、实例幂等、租期、清理。
3. 平台接入：管理员包预览／准备、学习和挑战共用环境交互、归属鉴权。
4. 来源与维护：GitHub 固定提交、手动更新、Dockerfile 构建、可写副本、取消／重试／强制重建。
5. 统一模型：移除单容器执行器和共享网桥；删除冗余数据库字段、旧规范与兼容入口；统一页面和 API，重建全新数据库基线。

本地测试通过与生产主机网络验收分别记录。真实 veth、反连和宿主防火墙需在具备 NET_ADMIN 的主机执行夹具；代码收敛不代表已经远程部署或验收。Compose 和 network_verified 开关仍需部署者显式设置。

当前操作以 [平台与全新部署说明](compose-platform-integration.md) 为准。后续跨主机网络、来源 GC、构建凭据或其他平台 provider 单独迭代，不重新引入双执行路径。
