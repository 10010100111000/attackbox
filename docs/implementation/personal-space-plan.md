# 个人空间：下一小轮规划

状态：计划，页面尚未实现。先做私有空间，不做公开个人主页或社交系统。

## 第一个可交付范围

增加 `/me` 和头像菜单中的真实入口，仅登录账号可访问：

- 顶部显示当前昵称与账号信息，不新增资料修改和头像上传。
- “最近学习”：复用 `/api/me/learning` 的模块进度和继续学习入口。
- “挑战记录”：复用 `/api/me/challenges` 的阶段通过记录，展示未完成／已完成与进入挑战入口。
- 为没有记录的新用户提供学习／挑战入口，不展示示例成就或假的画像。

当前挑战接口以已通过阶段为依据，只有错误提交不会产生“已参与”记录。若个人空间需要展示最近打开或尚未通过首阶段的挑战，再单独增加访问记录，不将错误 Flag 文本作为历史保存。

首轮使用记录列表，不从最多 20 条的学习历史推算“全站累计统计”。若后续需要总完成数或累计时长，分别增加准确的聚合查询或真实采集，不维护另一套可漂移的完成状态。

挑战完成表示当前已发布挑战的全部现有阶段已通过。新增阶段后可继续完成；下架记录在库中保留，但不提供跳转到不可访问内容；删除挑战会清理关联记录。公开展示成就前再单独确定历史保留政策。

## 接口与权限

现有两个接口都按会话读取本人记录。个人空间 SSR 与客户端切换账号必须清理缓存，不接受用户 ID 参数来查看其他人的私有数据，不返回标准答案、提交内容或环境凭据。

## 验收

- 访客跳转登录，登录后回到个人空间。
- 学习一章、通过一个挑战阶段后，刷新与重新登录能恢复真实记录。
- 继续入口和挑战入口能直达可访问内容；新账号正常空态。
- 账号切换不串用数据；不将受限内容或答案写入公开 HTML／共享缓存。

本小轮暂不做资料修改、公开主页、头像上传、积分、徽章、排行榜、画像和会员。Docker 目标运行仍按独立小迭代推进，不与个人空间页面同时扩展。
