# 内容分类

模块编辑器使用固定 38px 高的分类按钮；打开后以 Reka Dialog Portal 在右侧展示分类管理抽屉，不改变页面文档流。选择、新建、搜索、重命名、删除集中在同一界面，旧下拉和新建弹窗已移除。

默认分类只是数据库初始数据，没有特殊不可删除规则。重命名保留 ID 和 slug，不影响模块关联。删除前显示引用数量；确认后在同一事务中将关联模块改为未分类，再删除分类，不改变正文和发布状态。引用数量变化时要求重新确认。当前编辑器仅在版本未发生其他变化时接收这次分类操作产生的新版本，保留未保存的正文修改。名称唯一，修改和删除携带当前名称检测冲突。未保存的新模块选中的分类删除后恢复为未分类。

管理员 API：GET /api/admin/categories、POST /api/admin/categories、PATCH /api/admin/categories/:id、DELETE /api/admin/categories/:id。所有写操作校验管理员身份及请求来源，删除事务锁定分类并保留外键保护。

运行本地集成测试：配置仅指向本机独立 `_test` 数据库的 CONTENT_TEST_DATABASE_URL 和 CONTENT_TEST_BASE_URL，再在 web 下执行 npm run test:categories。测试包含权限、名称冲突、引用统计、删除确认与模块保留、浏览器 CRUD 以及抽屉展开时编辑器位置不变。

本轮不需要数据库迁移。分类删除属于立即生效的全局操作，模块编辑器中的其他修改仍需单独保存。
