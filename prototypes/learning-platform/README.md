# AttackBox 学习平台原型

保存当前确认的用户端设计，作为 Nuxt 开发的参考。`index.html` 为无外部依赖的单文件原型，不需要安装依赖。

## 打开方式

直接用浏览器打开 `index.html`，或在仓库根目录执行：

```sh
python3 -m http.server 8080 --directory prototypes/learning-platform
```

使用本地 HTTP 服务可更稳定地体验复制命令和浏览器本地存储。打开页面后默认进入学习首页。

## 页面与交互

| 地址片段 | 页面 |
| --- | --- |
| `#modules` | 学习模块首页，含自动轮播宣传位 |
| `#paths` | 学习路线列表 |
| `#path` | 路线详情：多个模块的有序组合 |
| `#roadmap` | Linux 模块详情：章节大纲 |
| `#lesson/0` | 学习正文、输入答案练习、CLI / GUI 面板 |
| `#challenges` | 挑战靶场布局示例 |
| `#discuss` | 讨论占位原型，论坛功能暂不实现 |
| `#profile` | 个人中心示例 |
| `#progress` | 学习记录 |

- 顶部导航为“学习 / 挑战 / 讨论”。头像菜单包含个人中心、学习记录和石墨 / 深海外观切换。
- 首页轮播包含精选路线、挑战推荐、模块推荐；每 6 秒切换，支持手动翻页、暂停、键盘和触摸滑动。悬停、焦点进入和页面隐藏时暂停；减少动态效果偏好下默认不自动播放。
- 学习正文使用宽版排版；模块目录可以收起，手机上以抽屉展开。只保留一个“返回模块”入口。
- CLI / GUI 仅在顶部切换。底部练习面板支持调节高度、展开、收起和关闭，关闭面板不表示释放环境。
- 章节练习与正文等宽，标题和正文采用一致的排版。逐题输入、校验，全部通过后解锁下一章。
- 演示进度、主题、目录收起状态和投稿草稿使用浏览器本地存储。不同访问来源的本地状态相互独立。

## 实现边界

这是设计评审用的前端原型，未接入真实账号、权限、内容源、靶场、终端、远程桌面或投稿服务。演示终端仅返回少量固定命令结果，不执行系统命令；GUI 为布局占位。

练习答案与判题逻辑在原型浏览器端，仅用于体验交互；正式版本必须在服务端完成授权、判题和章节解锁。讨论保留设计探索记录，不属于当前实现范围。

后续计划：先确认管理员的模块、章节、路线和轮播发布流程，再实现 Nuxt 学习平台，之后接入沙箱，最后迁移并移除 Go Control。

本文件保留多轮设计迭代后的效果。Nuxt 实现时应重新组织组件、样式和状态，不直接复用叠加的原型代码。
