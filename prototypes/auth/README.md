# 登录与账户原型

打开 `index.html` 即可体验，无构建依赖、无运行时外部请求。首页“进入平台”已连接到此原型。

## 设计

沿用首页深色与珊瑚色，桌面左侧品牌氛围、右侧登录表单；手机隐藏氛围区，集中展示表单。使用现有项目的邮箱登录形式。

## 可体验交互

- 邮箱与密码校验、行内错误提示、错误焦点定位。
- 密码显示与隐藏、Caps Lock 提示、保持登录状态复选框。
- 登录加载与成功状态预览，可继续打开学习平台原型。
- GitHub / 单点登录入口提示，注册与找回密码表单状态。
- 标准标签、自动填充属性、键盘操作与响应式布局。

这是独立的设计原型。任何满足格式的输入都可预览成功状态，不会验证真实身份，不提交网络请求，不保存密码，不创建账户或发送邮件。“保持登录状态”仅展示控件，尚未接入会话设置；第三方入口尚未接入身份提供方。
