# 学习内容管理原型

无外部依赖的单文件 HTML。直接打开 `index.html`，或从仓库根目录运行：

```sh
python3 -m http.server 8080 --directory prototypes/learning-admin
```

## 评审入口

| 地址片段 | 页面 |
| --- | --- |
| `#overview`（默认） | 内容库统计、学习趋势、转化漏斗、学习者画像与待处理内容 |
| `#modules` | 模块列表、搜索、状态筛选、新建模块 |
| `#module/linux` | 章节编排、Markdown 来源、本地编辑与阅读预览、输入式练习 |
| `#routes` | 路线列表与新建路线 |
| `#route/intro` | 选择已有模块、排序、移除与路线预览 |
| `#users` | 用户搜索、状态与角色筛选、分页、新建示例账户 |
| `#user/lin` | 用户资料、学习记录、角色调整、停用恢复、管理日志 |
| `#user/lin/environment` | CLI / GUI 使用量、实例状态、会话控制与环境策略 |
| `#nodes` | Worker 状态、资源与新实例分配控制 |
| `#node/worker-01` | 节点详情、运行实例与节点管理记录 |
| `#instances` | 跨用户实例列表，支持搜索与节点筛选 |
| `#homepage` | 首页轮播编辑、排序、草稿与已发布版本预览 |
| `#control` | 系统设置：站点、登录认证、服务接入、域名与证书 |

头像菜单切换石墨 / 深海配色。草稿和模拟发布版本保存在浏览器 localStorage 中，不会修改真实网站。

新建模块只需填写名称，访问标识留空时自动生成；填写无效或重复标识会在对应输入框下提示。创建完成立即进入章节编辑。如浏览器拒绝本地保存，仍可在内存中继续编辑，但会明确提醒刷新后丢失，不表示持久化成功。

## 内容概览

- 内容库中的模块、发布状态、草稿、路线、章节数量来自当前本地编辑状态。
- 学习指标、趋势、漏斗、模块表现与画像是固定演示样本，并非真实用户数据。
- 支持近 7 / 30 天、全部 / 新 / 回访学习者切换。新与回访人群互斥。
- 基础水平和兴趣画像来自演示的用户自报信息；正式版应标明样本量、未填写比例，对小样本隐藏分布。
- 待处理内容关联实际草稿，可直接进入编辑。

## 用户管理

- 使用独立的少量示例用户，不与概览中的统计样本对应；不含会员体系。
- 账户状态、管理员角色与学习记录独立。支持搜索用户名、邮箱和 ID，按状态或角色筛选。
- 管理员可添加示例用户、保存内部备注、调整角色、停用及恢复账户；不发送邮件、不设置真实密码、不影响真实会话。
- 当前管理员不能停用自己或调整自己的角色，并保留至少一个正常管理员的校验。
- 学习记录只读；停用、恢复与角色调整不改变进度。备注不展示给普通用户。
- 变更记录到本地管理日志。保存失败时回滚用户变更，不显示为操作成功。

## 远程环境与账户关联

- 用户列表显示是否有运行环境，以及 CLI / GUI 连接情况，可直接进入该用户的“环境与会话”。
- 分别统计近 30 天 CLI 连接累加时长、GUI 连接时长和实例占用时长。多终端并发时连接时长可能超过实例占用时长，不代表有效交互时间。
- CLI“结束会话”关闭对应连接与 PTY；GUI“断开连接”保留桌面；“释放整个环境”结束全部终端、桌面及进程，不清除学习记录。
- 账户停用时断开其 CLI / GUI 连接，结束 CLI 会话；实例与 GUI 桌面仍保留到回收或管理员主动释放。恢复账户不会自动重建连接。
- 环境策略允许禁止新接入，并设置最长运行时长、无交互回收阈值。时限变更只影响新建实例，不修改当前剩余时间。
- 所有控制都是本地模拟，固定快照不实时计时；未向 Worker 发送指令。正式版本应显示请求中、失败或待确认状态，收到 Worker 确认后才标记已释放。

## 节点与实例

- 平台概览增加在线节点、已知运行实例、离线待核对与首页发布数量入口。
- 节点示例覆盖在线可分配、暂停分配且磁盘水位偏高、离线三种情况。
- 暂停新分配保留当前实例及会话；恢复分配需要节点在线，原型对高磁盘水位另有阻止提示。
- 离线节点不显示伪造的实时 CPU / 内存，也不把上次实例数量当成已释放。实例列表仅为已知清单，明确提示离线节点可能仍有环境。
- 跨用户实例可按节点与用户检索，查看详情或释放。释放与用户详情共用同一份本地环境状态，并记录用户管理日志。
- 接入说明描述 Worker 主动登记流程，不提供远程命令执行、真实凭据或升级操作。

### 节点配置

- 节点详情增加“运行概览 / 节点配置”两个页签。
- 配置包含名称、标签、备注、WSS 数据网关基准地址、实例容量、心跳间隔与磁盘保护阈值；节点 ID 只读。
- 保存后形成期望版本，保留原已确认版本。可查看差异，并通过明确标注的“模拟 Worker 确认应用”更新本地已确认快照；离线节点不能确认。
- 时限和单实例资源在节点管理的默认运行策略中统一配置，并保留用户覆盖。节点文件路径、网络桥接、集群身份与私钥仍由部署维护。
- 网页配置下发、确认协议和节点容量管理是未来 Nuxt Control 的设计，不是当前 Go Worker 已实现的能力。原型不写入实际 YAML 配置。

## 节点默认运行策略

- 在“节点管理 → 默认运行策略”维护 TTL、无交互回收、单实例资源、心跳和 RPC 超时。
- 登录有效期和一次性接入 Ticket 有效期移到系统的“登录与认证”。修改节点默认策略不会清零或覆盖认证设置。
- 运行策略由未来 Nuxt Control 下发并由 Worker 执行，页面归属不改变后端权威校验边界。

## 系统设置

- 站点设置：名称、HTTPS 地址、注册与公告。
- 登录与认证：保留本地管理员登录，管理登录有效期和 CLI / GUI 接入 Ticket 有效期。
- 服务接入：独立配置邮件、单点登录、Cloudflare Turnstile，不提供独立内容源管理。
- 邮件支持 Resend API 或 SMTP（TLS / STARTTLS）；单点登录支持 GitHub OAuth 或企业 OIDC，并生成只读回调地址。
- Turnstile 使用专用 Site Key / Secret Key，可选择注册、登录、找回密码场景，不需要 Cloudflare 通用 API Token。
- 密码输入仅用于原型交互，绝不写入 localStorage、预览、截图或日志；只持久化“密钥已配置”的布尔标记。请勿输入真实凭据。
- 状态区分未配置、已配置未验证、模拟验证通过、模拟失败，以及是否启用。测试不发送邮件、不打开真实授权、不请求 Cloudflare；由评审者选择模拟结果。
- 配置修改会重置测试并停用服务。模拟通过后才可启用，清除密钥标记会停用服务。第三方登录不关闭本地管理员登录。
- 域名与证书页显示站点域名、部署侧维护边界和“尚未检查”状态，不伪造有效期或已验证结果，不上传私钥。
- 移除旧的静态运行状态介绍页。运行数量与异常在平台概览、节点页查看；不提供程序重启、升级、DNS 自动化、R2 或对外 API 密钥管理。

## 首页轮播

- 最多五项，管理栏目标签、标题、简介、按钮文字、目标内容、启用状态与配图方式。
- 跳转目标选择已有模块、路线或挑战列表，不依靠手工填写任意跳转地址。
- 拖动及上下按钮排序，预览草稿与本地已发布快照；只发布启用项。
- 发布检查目标内容已发布、文字必填及 HTTPS 图片地址；未发布路线不能被启用上线。
- 配图支持默认终端插画、HTTPS 图片链接或不配图。预览图片链接会请求该外部地址。
- 发布仅保存本地快照，未写入用户端原型或真实网站。

## 设计规则

- 模块包含章节，路线引用已有模块；路线不复制模块内容。
- 在模块级保存草稿、确认发布。发布前检查名称、访问标识、章节、HTTPS 来源和已配置的练习题。
- 修改草稿不会覆盖已发布快照。已发布模块更新后，路线继续引用同一模块。
- 发布路线前，所有被引用模块必须已发布。下架模块时，原型会同时下架引用它的已发布路线。
- 章节和路线模块均支持拖动排序、上下按钮排序；后者也便于键盘和手机操作。
- 每道练习配置题目、标准答案和错误提示，用户端使用输入答案校验。
- 来源同步仅展示流程，不实际请求 GitHub；Markdown 为本地示例，可编辑后预览。

## 范围

本原型用于打磨 UI / UX，不包含真实登录授权、远端内容同步、服务端判题、审核或生产发布。Markdown 预览仅支持演示所需的标题、段落和代码块，并转义 HTML；正式版应采用完整渲染与安全策略。

保存草稿为显式操作，支持 Ctrl / Command + S。刷新或关闭有未保存修改的页面会触发浏览器提醒；内部页面切换暂保留内存中的编辑状态。
