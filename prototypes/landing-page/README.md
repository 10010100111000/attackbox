# AttackBox 首页原型

当前版本：单一模糊终端背景 + 主推模块与横向模块架。

直接打开 `index.html`，或在 `prototypes` 目录启动静态服务。页面脚本和图片均已内嵌，运行时无需 CDN、WebGL 或后端。

## 首屏

顶部只保留品牌和“进入平台”。首屏只保留主标题与“开始学习”按钮；导航、顶部 GitHub、小标语、副文案、次要入口和切换控件均已移除。

背景自动轮播 Nmap 服务识别、smbclient 共享枚举、msfconsole 模块搜索。仅为脚本演示，不执行真实命令或扫描。单一终端在固定位置逐字输入，显示结果后清屏继续，无第二条日志流、无整屏滚动。按本轮要求默认自动播放；系统偏好减少动态效果时降低播放速度并关闭装饰过渡，后台标签暂停播放时间累计。

## 模块区

“下一步，动手。”居中衔接首屏；移除辅助标题、全部模块入口和难度筛选。

云原生攻防作为大幅主推模块，其余五个模块组成横向模块架。模块架自动缓慢循环，不显示滚动条和滑动按钮；鼠标悬停或键盘聚焦时暂停，手动操作后延迟恢复。支持触摸、触控板和键盘浏览；循环副本从辅助技术和 Tab 导航中排除。卡片保留微光与悬停效果。点击直接进入模块路由，无弹窗。

章节数量为示例。新增进阶模块保留 `#module/cloud`、`#module/reverse`、`#module/container` 路由入口，目标页面待正式实现。

## 构建

```sh
npm ci
npm run build
```

`src/index.template.html` 包含布局和卡片，`src/scene.js` 包含终端演示与交互，`build.mjs` 生成独立 HTML。当前构建只依赖 esbuild，已移除 Three.js 依赖与许可证复制步骤。旧版实验文件保留在本地归档，不纳入当前首页提交。样式已统一重写，移除历次叠加的粒子、双日志、弹窗、筛选和旧导航代码。图片来源见 `ASSETS.md`。
